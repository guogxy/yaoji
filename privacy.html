隐私政策

更新于 2026-10-16

爻记是一款以本机排卦、卦例整理和传统典籍阅读为核心的工具。开发者为 Xinyu Guo。本政策适用于爻记 App 与本官网。

App 内的数据

App 不要求注册账号，不内置广告、用户行为分析或第三方追踪 SDK，不向开发者服务器上传卦例、事件数字、笔记、标签、照片或设备标识。开发者无法远程读取你的本机资料库。

你输入的事项、起卦参数、日期时间、卦例、标签、笔记、复习记录及偏好保存在 App 本机存储中，用于排卦、检索和恢复自己的记录。设备当前时区仅用于本机日期计算，不用于获取地理位置。

照片、文件与摇一摇

截图识别由设备上的 Apple Vision 完成，不发送到在线 OCR 或 AI 服务。照片由系统照片选择器提供，App 只能读取你主动选择的图片，不扫描整个相册。选择保存在 iCloud 的照片或文件时，系统可能按照你的设置下载该项目。

导入备份时，App 读取你在系统文件选择器中选定的文件；导出或分享时，资料只发送到你主动选择的目标。摇一摇使用系统摇动事件触发本机铜钱模拟，不记录或上传运动轨迹。App 不请求相机、麦克风、通讯录或定位权限。

备份、保留与删除

本机资料保留到你删除为止。卦例移入“最近删除”后仍可恢复；在“最近删除”中永久删除后，App 资料库不再保留该卦例。标签和笔记可在 App 中自行管理。卸载 App 会移除设备上的 App 本机数据，但不自动删除你另行保存的副本。

完整备份是未额外加密的 JSON 文件，可能包含事项、笔记和标签等私人内容，请妥善保管，谨慎分享。你保存到文件服务、邮件或其他 App 的副本，由相应服务管理。

App 没有自建云同步服务；iOS/iPadOS 设备备份可能包含 App 数据，取决于你的系统及 iCloud 设置。你可以在系统设置中管理此类备份。我们无法代你删除设备备份、导出文件或其他服务中的副本。

联系支持与访问官网

联系支持完全自愿。你发送邮件时，我们会收到发件地址、邮件内容和你主动提供的附件，仅用于回复、排查问题或处理隐私请求，不用于广告营销。请不要发送无关的敏感信息或完整私人资料库；需要示例时，优先提供去除个人信息的片段。

支持邮件仅在解决请求及合理后续沟通所需的期限内保留，法律另有要求的除外。你可以发送邮件请求查阅、更正或删除你主动提交给我们的信息。

官网托管于 GitHub Pages，没有自行添加统计脚本、广告追踪、Cookie 或表单。访问网站时，GitHub 可能为安全和运营目的记录 IP 地址等网络日志，适用 GitHub 的隐私声明。打开外部网页、邮件或系统服务后，也适用相应服务的隐私规则。

政策更新与联系

我们会在功能或数据处理方式发生变化时更新本政策及生效日期。当前 App 不向开发者提供用户数据用于追踪、出售或定向广告。有关隐私的问题或删除请求，请联系 guogxy@hotmail.com。
