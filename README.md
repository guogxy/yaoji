# YaoJi / 爻记 official website

Static product, privacy, support, terms and license pages for 爻记.

Published with GitHub Pages from `main` at https://guogxy.github.io/yaoji/.

Run `node build.mjs` to regenerate HTML from `content.json`. No dependencies,
client-side scripts, analytics, forms, third-party fonts or remote images.

`content.json` is also bundled as `YaoJi/Legal/legal-content.json` in the app;
when editing policies, update both copies from this source and verify equality.

Product screenshots contain demonstration records only. The icon is the existing
App icon, unchanged. This repository does not contain the app's private source,
user records, backups, PDFs, signing credentials or App Store account material.

The textual corpus has its own CC BY-SA 4.0 terms in
`licenses/ZhouYi-NOTICE.txt`. Other third-party licenses are in `licenses/`.
